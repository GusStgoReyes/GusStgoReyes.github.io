# Gustavo X Santiago-Reyes — Personal Science Website

## File structure

```
index.html              ← Main site (don't edit content here)
data/
  research.js           ← ✏️  Edit to update research interest cards
  blog.js               ← ✏️  Edit to add/update blog posts
  visualizations.js     ← ✏️  Edit to add/update visualization cards
```

## How to update content

**Add a blog post:** Open `data/blog.js`, copy the example entry, set `coming: false`, add your URL.

**Add a visualization:** Open `data/visualizations.js`, set `coming: false`, add the URL to your viz page.

**Update research cards:** Open `data/research.js` and edit any entry.

## GitHub Pages setup

1. Create a repo named `yourusername.github.io` on GitHub
2. Push all these files to the `main` branch
3. Go to Settings → Pages → Source: `main` branch, `/ (root)`
4. Your site will be live at `https://yourusername.github.io`
